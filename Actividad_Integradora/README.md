# Analizador de frecuencias

Este script lee el archivo texto_integradora.txt, cuenta cuántas veces aparece cada palabra y crea un gráfico de barras con las 10 palabras más frecuentes. El gráfico se guarda como grafico_frecuencias.png. Si no encuentra el archivo de texto, muestra un mensaje de error.

Para usarlo hay que tener instalado Python y las bibliotecas matplotlib y pytest:

pip install matplotlib pytest

Para ejecutarlo, desde la carpeta donde están los archivos:

python analizador.py

Para correr las pruebas:

pytest -v
